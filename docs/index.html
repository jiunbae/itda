Windows와 Mac에서 다른 기기의 화면과 파일에 연결하세요. 휴대폰과 태블릿에서는 브라우저로 저장한 기기를 열 수 있습니다. Connect to your devices’ screens and files from Windows or Mac. Open saved devices from a browser on your phone or tablet.

Windows용 다운로드Download for Windows · 무료· Free Mac용 다운로드Download for Mac 휴대폰에서 쓰기Use it on a phone · 앱 설치 없음· No app

휴대폰은 브라우저로 씁니다. 먼저 Mac이나 Windows PC에 Itda를 설치해 켜 두고, 그 컴퓨터의 공유 페이지 QR을 휴대폰 카메라로 찍은 뒤 6자리 PIN을 넣으세요. 휴대폰은 그 컴퓨터와 같은 Wi-Fi(또는 Tailscale)에 있어야 합니다.Phones use a browser. First install and run Itda on a Mac or Windows PC, then scan the QR on its Share page with your phone's camera and enter the 6-digit PIN. The phone must be on the same Wi-Fi (or Tailscale).

기기와 계정을 한곳에서 관리하고, 화면 연결과 파일 탐색을 각각의 창에서 사용하세요.Keep devices and accounts in one place, with separate windows for remote screens and files.

Windows·Mac 앱Apps for Windows and Mac

Windows 실행 파일과 Apple Silicon·Intel용 Mac 앱을 제공합니다. 로컬 커서와 변경 영역 갱신으로 화면 전송을 줄입니다.A Windows executable and a universal Mac app for Apple silicon and Intel. Local cursors and changed-region updates reduce screen traffic.

Mac 화면 공유 그대로Mac Screen Sharing, built in

상대 Mac의 기본 화면 공유를 켜고 Mac 계정으로 로그인하세요. Mac에서는 Apple 화면 공유 앱으로 여는 옵션도 제공합니다.Enable built-in Screen Sharing on the remote Mac and sign in with its Mac account. On Mac, you can also choose Apple’s Screen Sharing app.

Windows PC · RDPWindows PCs · RDP

다른 PC의 Itda 공유(Home 포함) 또는 원격 데스크톱(Pro·Enterprise·Education)으로. Mac 앱과 브라우저에서도 RDP를 열고, 해상도가 창 크기를 따라갑니다.Via Itda’s Share this PC (including Home) or Remote Desktop (Pro, Enterprise or Education). The Mac app and browsers open RDP too, and the desktop follows the window size.

어디서나 브라우저로Your devices in a browser

Windows 또는 Mac의 Itda에서 웹 뷰어를 켜세요. 같은 네트워크나 Tailscale에서 QR과 PIN으로 접속하고 홈 화면에도 추가할 수 있습니다.Enable the web viewer in Itda on Windows or Mac. Connect with a QR code and PIN over your network or Tailscale, and add it to your home screen.

SSH 암호화SSH encryption

상대 기기의 SSH가 켜져 있다면 화면 연결을 SSH 터널로 보호하세요. 암호와 키 파일을 지원합니다.When the remote device runs SSH, use a tunnel to protect the screen connection. Passwords and key files are supported.

Tailscale로 어디서나Anywhere with Tailscale

공유기 설정 없이 집 밖에서도. Tailscale 기기를 자동으로 찾고 HTTPS 주소도 만들어 줍니다.No port forwarding. Tailscale devices show up automatically, and Itda can mint an HTTPS address.

별도 창에서 파일 탐색A window for your files

화면 공유 없이 SSH/SFTP로 폴더를 열고 복사·이동하세요. 탭과 미리보기, Mac의 열·갤러리 보기도 지원합니다.Browse and transfer over SSH/SFTP without opening a remote screen. Use tabs and previews, plus column and gallery views on Mac.

여러 모니터, 여러 창More displays, more windows

원격 기기가 보고하는 모니터를 선택하거나 각각의 창으로 분리하세요. 모니터 정보를 제공하지 않는 연결은 수동 분할로 배치합니다.Choose a reported remote display or open displays in separate windows. Use manual splits when the server does not report its monitors.

작동 방식How it works

내 컴퓨터가 연결의 중심Your computer is the bridge

Windows·Mac 앱은 상대 기기에 연결하고, 웹 뷰어는 Itda를 실행 중인 컴퓨터를 통해 화면을 전달합니다.The Windows and Mac apps connect to your remote devices. The web viewer relays their screens through your own computer running Itda.

브라우저 ↔ 내 컴퓨터: PIN 로그인, 화면·입력·클립보드Browser ↔ your computer: PIN sign-in, screens, input and clipboard 내 컴퓨터 ↔ 기기: 저장 계정으로 인증, SSH 터널 선택Your computer ↔ devices: saved credentials, optional SSH tunnels
1기기에서 공유 켜기Turn on sharing

Mac은 화면 공유, PC는 Itda 공유나 원격 데스크톱, Linux는 VNC 서버.Screen Sharing on a Mac, Itda sharing or Remote Desktop on a PC, a VNC server on Linux.

2Itda에 추가Add it to Itda

주변 기기에서 ‘추가’를 누르거나 주소를 입력하고 계정을 저장합니다.Click Add in Nearby, or type an address and save the account.

보안Security

저장한 암호는
운영체제 보관소에Saved passwords stay
in the OS credential store

Itda 계정을 만들 필요가 없습니다. 웹 뷰어는 저장된 접속 암호를 브라우저에 보내지 않고, 앱이 상대 기기에 인증합니다.No Itda account is required. The app authenticates with the remote device without handing its saved connection passwords to the web browser.

자격 증명 관리자 · 키체인Credential Manager · Keychain

암호와 키 암호는 Windows 자격 증명 관리자나 Mac 키체인이 암호화해 보관합니다. 설정 파일에는 저장하지 않습니다.Passwords and key passphrases are kept encrypted by Windows Credential Manager or the macOS Keychain, never written to settings files.

Apple 인증 · NLAApple auth · NLA

Mac은 Apple의 DH + AES 로그인, RDP는 TLS와 네트워크 수준 인증(NLA)으로 접속합니다.Macs sign in with Apple's DH + AES scheme; RDP uses TLS with Network Level Authentication.

PIN과 잠금PIN & lockout

웹 뷰어는 6자리 PIN → HttpOnly 쿠키. 5번 틀리면 잠기고, 다른 사이트의 접속(Origin)은 거부합니다.The web viewer uses a 6-digit PIN → HttpOnly cookie, locks after 5 misses and rejects cross-site requests.

허락을 묻는 공유Sharing that asks first

Windows의 ‘이 PC 공유’는 연결 허용 여부를 묻도록 설정할 수 있습니다. 같은 네트워크 연결을 자동 허용하는 옵션과 현재 접속자 표시도 제공합니다.Windows Share this PC can ask before allowing connections. You can configure same-network exceptions and see the current viewers.

권장: 웹 뷰어와 이 PC 공유는 같은 Wi-Fi나 Tailscale 안에서 쓰세요. 공유기에서 포트를 인터넷에 직접 열지 마세요. 밖에서는 Tailscale의 HTTPS 주소를 쓰면 됩니다.Recommended: use the web viewer and Share this PC on your own Wi-Fi or over Tailscale. Don't forward these ports to the internet — use Tailscale's HTTPS address when you're away.

FAQ

자주 묻는 질문Questions

고성능 모드의 화질과 권한은 어떻게 설정하나요?How do I set high-performance quality and permissions?

원격 Mac에 SSH로 Itda를 설치하고 그 Mac의 권한 도우미에서 화면 기록·손쉬운 사용을 허용합니다. ‘빠르게’가 기본이며, ‘선명하게 (Retina)’를 켜면 글자가 또렷해지는 대신 프레임이 줄 수 있습니다. 잠금·다른 사용자·권한 문제는 기본 화면 공유로 전환해 안내합니다. 설정 방법 보기Install Itda on the remote Mac over SSH and grant Screen Recording and Accessibility through its permission helper. Fast is the default; Sharp (Retina) improves text detail at a possible frame-rate cost. Lock, other-user and permission conditions fall back to built-in Screen Sharing with an explanation. Setup guide

정말 무료인가요?Is it really free?

네. MIT 라이선스의 오픈 소스이고, 가입·구독·광고가 없습니다.Yes. It's open source under the MIT license — no sign-up, subscription or ads.

Mac에 무엇을 설치해야 하나요?What do I install on the Mac?

기본 화면 연결을 받는 Mac에는 별도 앱이 필요 없습니다. 시스템 설정 → 일반 → 공유에서 ‘화면 공유’를 켜세요. 파일 브라우저나 SSH 터널을 쓰려면 ‘원격 로그인’도 켜고 계정 접근을 허용해야 합니다. 선택 기능인 고성능 모드는 상대 Mac에도 Itda를 설치하며 화면 기록·손쉬운 사용 권한이 필요합니다.The remote Mac needs no additional app for basic screen access. Enable Screen Sharing in System Settings → General → Sharing. Enable Remote Login and allow your account for file browsing or an SSH tunnel. Optional high-performance mode also installs Itda on the remote Mac and needs Screen Recording and Accessibility permissions.

Mac·iPhone에서는 어떻게 쓰나요?How do I use Itda on Mac or iPhone?

Mac: 공식 릴리스에서 Itda-macos-universal.zip을 받아 압축을 풀고 Itda.app을 응용 프로그램 폴더로 옮기세요. 공식 앱은 Developer ID 서명과 Apple 공증을 거칩니다. iPhone: Windows 또는 Mac의 Itda에서 웹 뷰어를 켜고 Safari로 열어 홈 화면에 추가하세요.Mac: download Itda-macos-universal.zip from official releases, unzip it and move Itda.app to Applications. Official apps are Developer ID-signed and Apple-notarized. iPhone: enable the web viewer in Itda on Windows or Mac, open it in Safari and add it to your Home Screen.

Microsoft 계정으로 로그인하는 PC에 원격 데스크톱으로 들어가려면?Remote Desktop into a PC that signs in with a Microsoft account?

계정에 이메일 주소, 암호에 그 Microsoft 계정 암호를 넣으세요. 로그인 화면의 숫자 PIN이나 얼굴 인식은 원격 접속에 쓸 수 없습니다. 계속 실패하면 Microsoft 계정 암호와 해당 계정의 원격 데스크톱 접근 권한을 확인하세요. Windows · Itda로 추가한 PC는 Windows 암호가 아니라 그 PC의 공유 암호(8글자)를 씁니다.Use the email address as the account and the Microsoft account password — the sign-in PIN or face unlock won't work remotely. If it keeps failing, verify the Microsoft account password and that the account is allowed to use Remote Desktop. A PC added as Windows · Itda uses its 8-character share password instead.

Windows Home 에디션도 연결되나요?Does Windows Home work?

네. Windows Home에는 원격 데스크톱 서버가 없지만, 그 PC에 Itda를 설치하고 ‘이 PC 공유’를 켜면 Home을 포함한 지원 Windows 에디션에서 연결할 수 있습니다.Yes. Home has no Remote Desktop host, but install Itda on it and turn on Share this PC — that works on every supported edition, including Home.

집 밖에서는 어떻게 연결하나요?How do I connect from outside?

모든 기기에 Tailscale을 설치하고 같은 계정으로 로그인하세요. Itda가 Tailscale 기기를 자동으로 보여 주고, 웹 뷰어의 Tailscale 주소·HTTPS 주소도 만들어 줍니다.Install Tailscale on every device and sign in with the same account. Itda lists your Tailscale devices and shows the web viewer's Tailscale/HTTPS address.

Windows가 “PC를 보호했습니다”라고 해요.Windows says “Windows protected your PC”.

아직 코드 서명이 없는 새 앱이라 SmartScreen이 경고합니다. ‘추가 정보’ → ‘실행’을 누르세요. 소스와 빌드 방법은 GitHub에 공개되어 있습니다.The app isn't code-signed yet, so SmartScreen warns about it. Click “More info” → “Run anyway”. Source and build steps are on GitHub.

RealVNC·TeamViewer와 무엇이 다른가요?How is it different from RealVNC or TeamViewer?

계정·클라우드 없이 Mac의 기본 화면 공유와 Windows 원격 데스크톱 같은 표준 프로토콜을 그대로 씁니다. 기본 Mac 화면 공유와 RDP는 상대 기기의 기존 서버를 사용하고, Windows의 Itda 공유는 상대 PC에도 Itda가 필요합니다.No accounts or cloud: Itda speaks the standard protocols your devices already have — Mac Screen Sharing, Windows Remote Desktop, VNC. Built-in Mac Screen Sharing and RDP use the remote device’s existing server; Itda’s Windows sharing requires Itda on that PC.
