다운로드하고 실행하기Download and run

  1. Windows: itda.exe를 받습니다. 설치 과정 없이 실행 파일 하나입니다. Mac: Itda-macos-universal.zip을 받아 압축을 풀고 Itda.app을 응용 프로그램 폴더로 옮깁니다(macOS 12.3+, Apple 실리콘·Intel). 모든 버전은 릴리스 페이지에 있습니다.Windows: get itda.exe — no installer, a single executable. Mac: get Itda-macos-universal.zip, unzip it and move Itda.app to Applications (macOS 12.3+, Apple silicon · Intel). Every version is on the releases page.
  2. Windows는 실행 파일을 보관할 폴더에 두고 여세요. Mac은 응용 프로그램 폴더에서 Itda를 여세요.On Windows, keep the executable in a permanent folder and open it. On Mac, open Itda from Applications.
  3. Windows에서는 알림 영역, Mac에서는 Dock의 Itda 아이콘으로 메인 창을 다시 열 수 있습니다.Reopen the main window from the notification area on Windows or the Itda Dock icon on Mac.
“Windows의 PC 보호” 창이 뜨면 — 아직 코드 서명이 없는 새 앱이라 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르세요.If “Windows protected your PC” appears — the app isn't code-signed yet, so SmartScreen warns. Click More info → Run anyway.
공식 Mac 앱은 서명·공증되어 있습니다. Developer ID 서명과 Apple 공증을 거친 릴리스를 응용 프로그램 폴더에서 여세요. 확인할 수 없다는 경고가 계속되면 공식 릴리스를 다시 받고, 경고를 우회하기 전에 다운로드 출처를 확인하세요. ‘로컬 네트워크의 기기를 찾도록 허용’을 물으면 허용해야 주변 기기가 보입니다. 화면 공유 권한은 별도로 안내합니다.Official Mac apps are signed and notarized. Open the Developer ID-signed, Apple-notarized release from Applications. If macOS still cannot verify it, download the official release again and check its source before bypassing a warning. Allow local-network discovery when prompted so Nearby can find devices. Screen-sharing permissions have separate setup guidance.
Windows의 앱 화면은 Microsoft Edge WebView2로 그립니다. Windows 11에는 기본으로 있고, Windows 10에서 없다고 나오면 Microsoft에서 설치하세요.On Windows, the home screen uses Microsoft Edge WebView2, which ships with Windows 11. If Windows 10 says it's missing, install it from Microsoft.

Mac 연결하기Connect a Mac

Mac에는 아무것도 설치하지 않습니다. 기본 화면 공유를 켜기만 하면 됩니다.Nothing to install on the Mac — just turn on its built-in Screen Sharing.

  1. Mac에서 시스템 설정일반공유 로 가서 화면 공유를 켭니다. 이미 원격 관리를 쓰고 있다면 그대로 사용해도 됩니다. 원격 관리 옆 ⓘ → 옵션에서 연결할 계정에 관찰과 제어를 허용하세요.On the Mac open System SettingsGeneralSharing and turn on Screen Sharing. If Remote Management is already in use, keep it enabled. Under its ⓘ → Options, allow Observe and Control for the connecting account.
  2. 화면 공유 옆 ⓘ에서 접근 허용에 내 계정이 있는지 확인합니다.Click ⓘ next to Screen Sharing and check your account is in Allow access for.
  3. Itda의 주변 기기에서 Mac 옆 추가를 누르고, Mac 계정 이름(짧은 이름)과 로그인 암호를 넣은 뒤 저장 후 연결. Apple ID가 아닙니다.In Itda's Nearby, click Add next to the Mac, enter the Mac account short name and login password, then Save & connect. Not your Apple ID.
크게 보기 ↗Enlarge ↗

계정 이름이 헷갈리면 Mac 터미널에서 whoami. 여러 Mac에 같은 계정을 쓰면 계정을 만들어 고르기만 하세요.Unsure of the short name? Run whoami in Terminal. Same account on several Macs? Create an Account once and pick it.

집 밖에서 쓰려면 두 기기 모두에 Tailscale을 설치하고 같은 계정으로 로그인하세요. 원격 로그인만 켠다고 밖에서 연결되지는 않습니다. 원격 로그인은 화면을 SSH로 암호화하거나(연결 편집 → SSH로 암호화해서 연결) 파일 브라우저·고성능 모드를 쓸 때만 켜면 됩니다.Using it away from home? Install Tailscale on both devices and sign in with the same account. Remote Login alone does not make the Mac reachable from outside. Turn on Remote Login only to encrypt the screen with SSH (editor → Encrypt with SSH), or for the file browser and high-performance mode.

Windows PC 연결하기Connect a Windows PC

A. Itda 공유A. Itda sharing Home 포함Includes Home

  1. 그 PC에도 Itda를 실행하고 공유 → 이 PC 공유를 켭니다. 주소와 8글자 공유 암호가 나옵니다.Run Itda on that PC and turn on Share → Share this PC. You'll see its address and an 8-character share password.
  2. 방화벽이 물으면 개인 네트워크만 허용합니다.If the firewall asks, allow Private networks only.
  3. 내 Itda의 주변 기기에 Windows · Itda로 나타납니다. 추가 → 종류 Windows · Itda → 공유 암호만 입력. Windows 계정·이메일·Windows 암호는 쓰지 않습니다.It shows up in Nearby as Windows · Itda. Add it, kind Windows · Itda, enter the share password — not a Windows account, email or Windows password.
  4. 같은 네트워크나 내 Tailscale에서는 바로 연결됩니다. 그 밖에서 연결하면 그 PC 화면에 허락 창이 뜨고, 예를 눌러야 연결됩니다.From the same network or your tailnet it connects straight away. From anywhere else the other PC shows an allow prompt — click Yes.

B. 원격 데스크톱B. Remote Desktop Pro · Enterprise · Education

  1. 그 PC에서 설정시스템원격 데스크톱을 켭니다.On that PC turn on SettingsSystemRemote Desktop.
  2. Itda에서 종류 Windows 원격 데스크톱, 주소에 PC 이름이나 IP, 계정에 그 PC의 Windows 계정. Microsoft 계정이면 이메일 주소와 Microsoft 계정 암호를 넣습니다(숫자 PIN은 안 됩니다).In Itda pick Windows Remote Desktop, enter the PC name or IP and its Windows account. For a Microsoft account, use the email address and the Microsoft account password (the PIN won't work).
  3. Windows에서는 Windows 원격 데스크톱 앱으로, Mac 앱과 웹 뷰어에서는 Itda 창·브라우저로 열리며 해상도가 창 크기를 따라갑니다.On Windows it opens in the system Remote Desktop client; in the Mac app and the web viewer it opens in Itda's window or the browser, and the desktop follows the window size.
Windows Home에는 원격 데스크톱 서버가 없습니다. 그런 PC는 A 방법을 쓰세요.Windows Home has no Remote Desktop host — use option A there.

화면 공유와 별도로 파일 열기Browse files independently

  1. Mac의 시스템 설정 → 일반 → 공유 → 원격 로그인을 켜고 사용할 계정의 접근을 허용하세요. Windows·Linux는 접속 가능한 SSH/SFTP 서버와 계정이 필요합니다.On Mac, enable System Settings → General → Sharing → Remote Login and allow your account. Windows and Linux need a reachable SSH/SFTP server and account.
  2. Itda 메인 화면의 파일 브라우저를 누르면 별도 파일 창이 열립니다. 기기를 고르고 저장 계정이나 파일 연결 계정을 선택하세요. 화면 공유 세션은 필요하지 않습니다.Open File browser in the main window to get a separate file window. Choose a device and its saved or file-connection account. No screen-sharing session is required.
  3. 탭과 경로 표시로 폴더를 탐색하고 복사·이동하세요. 기기 선택은 같은 창에서 이동하며, ⌘ / Ctrl + 클릭 또는 ⌘N / Ctrl+N은 명시적으로 새 파일 창을 엽니다.Browse using tabs and the path bar, then copy or move files. Device selections stay in the same window; ⌘ / Ctrl-click or ⌘N / Ctrl+N explicitly opens another file window.

다른 기기로 드래그하면 대상 폴더를 고릅니다. Windows로 복사하는 새 파일명은 완성형 한글(NFC)로 기록하며, 같은 이름이 있을 때의 처리(둘 다 유지·바꾸기·건너뛰기)는 복사 전에 고릅니다. 보고 있는 폴더에 놓으면 같은 이름이 몇 개인지도 미리 알려 줍니다. 실패하거나 취소한 전송은 전송 목록에서 남은 항목만 다시 시도할 수 있습니다.Drag to another device to choose its destination folder. New Windows destination names use composed Unicode (NFC). You choose how to handle existing names (keep both, replace, skip) before copying; dropping into the folder on screen also tells you how many names already exist. A failed or cancelled transfer can be retried for what is left from the transfer list.

Mac의 아이콘·목록·열·갤러리 보기와 미리보기를 지원합니다. SMB 공유 폴더를 Finder·탐색기로 여는 동작은 상대 기기의 파일 공유 설정을 사용합니다.Mac supports icon, list, column and gallery views with previews. Opening SMB shares in Finder or Explorer uses the remote device’s file-sharing settings.

Mac 고성능 모드와 권한High-performance Mac mode and permissions

  1. 상대 Mac의 원격 로그인과 계정 접근을 허용한 뒤, 연결 편집 또는 뷰어의 고성능 모드를 켭니다. SSH로 상대 Mac에 Itda를 설치·업데이트합니다. 화면에 로그인한 계정으로 연결하세요.Enable Remote Login and account access on the remote Mac, then enable high-performance mode in the connection editor or viewer. Itda installs or updates the remote app over SSH. Use the account signed into that Mac’s desktop.
  2. 상대 Mac의 Itda 권한 도우미에서 화면 기록·손쉬운 사용을 허용합니다. 설정한 뒤에는 도우미의 다시 확인을 누르세요. macOS가 앱 종료·재시작이나 별도의 캡처 확인을 요청하면 안내를 따릅니다. 로컬 Mac에 부여한 권한이 원격 Mac으로 복사되지는 않습니다.On the remote Mac, grant Screen Recording and Accessibility through Itda’s permission helper, then check again. Follow macOS prompts to quit/restart the app or confirm capture. Permissions on your local Mac do not transfer to the remote Mac.
  3. 빠르게는 기본 포인트 해상도입니다. 글자를 더 또렷하게 보려면 뷰어의 선명하게 (Retina)를 켜세요. 프레임이 줄 수 있으며, 기존 고성능 연결이 모두 끝난 뒤 화질 변경이 적용됩니다.Fast uses the default point resolution. Enable Sharp (Retina) in the viewer for clearer text. Frame rate may decrease; quality changes apply after all existing high-performance viewers disconnect.
잠금 상태·다른 사용자 세션·권한 문제에서는 기본 화면 공유로 전환하고 이유를 표시합니다. 기본 화면 공유의 접근 허용도 설정하세요. Mac 로그인 화면 조작이 필요하면 Mac에서 Apple 화면 공유 앱에서 열기를 사용합니다.Lock, another user’s desktop or permission problems fall back to built-in Screen Sharing with an explanation. Configure access for that service too. For the macOS login-window path, use Open in Apple Screen Sharing on Mac.

다른 기기에 설치하고 설정 보내기Install on another device and send settings

먼저 Itda에서 대상의 SSH 파일 탐색이나 SSH 화면 연결을 사용해 호스트 키를 확인하세요. 설정 → 원격 기기에 설치·설정 공유에서 Mac·Windows 대상과 보낼 프로필을 선택합니다. 대상·호스트 키·전송 범위를 확인한 뒤 설치하며, 실행 중인 대상 앱은 먼저 종료해야 합니다.First connect through Itda’s SSH file browser or SSH screen connection to verify the host key. Open Settings → Install on another device / share settings and select a Mac or Windows destination and profiles. Check its host key and transfer scope before installing; close an already running destination app first.

암호·계정 SSH 키는 별도 선택 사항입니다. 공유 설정·SSH 신뢰 기록·macOS 권한은 복제하지 않습니다. 설치 후 대상 기기에서 Itda를 열고 필요한 권한을 허용하세요. 자동 실행은 설정 → 로그인하면 Itda 실행에서 켭니다.Passwords and account SSH keys are separate opt-in choices. Sharing settings, SSH trust records and macOS permissions are not copied. Open Itda on the destination after installation and grant the required permissions. Enable automatic startup through Settings → Start Itda at login.

Linux · 기타 VNCLinux & other VNC servers

x11vnc, TigerVNC, wayvnc, Raspberry Pi의 VNC 서버 등 표준 VNC 서버라면 연결됩니다. 연결 편집의 종류를 Linux · 기타 VNC로 고르고 VNC 암호를 넣으세요. 대부분 사용자 이름은 비워 둡니다.Any standard VNC server works — x11vnc, TigerVNC, wayvnc, Raspberry Pi's VNC. Choose Linux · other VNC as the kind and enter the VNC password; most servers need no user name.

포트가 5900이 아니면 주소 뒤에 붙입니다 (예: raspberrypi.local:5901). SSH가 켜진 기기라면 SSH 암호화도 쓸 수 있습니다.Add the port if it isn't 5900 (e.g. raspberrypi.local:5901). If the box runs SSH you can encrypt the connection too.

휴대폰·태블릿 브라우저로 보기View from a phone or tablet

iPhone·Android는 앱 대신 웹 뷰어를 사용합니다. Windows 또는 Mac의 Itda에서 웹 뷰어를 켜면 저장한 기기를 브라우저로 열 수 있습니다. Windows PC 자체를 보려면 ‘이 PC 공유’도 켜세요.iPhone and Android use the web viewer. Enable it in Itda on Windows or Mac to open saved devices in a browser. To view the Windows PC itself, also enable Share this PC.

휴대폰만으로는 연결되지 않습니다. Itda가 설치되어 켜져 있는 Mac 또는 Windows PC가 하나 있어야 하고, 휴대폰은 그 컴퓨터와 같은 Wi-Fi(또는 둘 다 Tailscale)에 있어야 합니다. 그 컴퓨터가 잠자기에 들어가거나 꺼지면 휴대폰에서도 연결이 끊깁니다.A phone can't connect on its own. You need a Mac or Windows PC with Itda installed and running, and the phone must be on the same Wi-Fi (or both on Tailscale). If that computer sleeps or shuts down, the phone loses the connection too.
  1. Itda 왼쪽 공유에서 웹 뷰어를 켭니다. Windows에서는 모두 켜기로 ‘이 PC 공유’도 함께 켤 수 있습니다. QR 코드와 6자리 접속 PIN이 표시됩니다.Open Share in Itda and enable the web viewer. On Windows, Turn on both also enables Share this PC. You get a QR code and a 6-digit PIN.
  2. 휴대폰 카메라로 QR을 찍거나 Mac 브라우저에 주소를 입력하고 PIN을 넣습니다.Scan the QR with your phone's camera (or type the address on a Mac) and enter the PIN.
  3. 기기를 눌러 엽니다. 기기 추가·편집·계정 관리도 여기서 됩니다.Tap a device to open it. You can add and edit devices and accounts here too.

가장 쉽고 안전한 방법은 Tailscale입니다. 공유기 설정 없이, 기기들이 어디에 있든 같은 네트워크처럼 연결됩니다(요금제는 Tailscale에서 확인).The easiest safe option is Tailscale: no router setup, and your devices behave as if they were on one network wherever they are (check Tailscale’s current plans).

  1. 웹 뷰어를 제공하는 컴퓨터, 상대 기기, 휴대폰에 Tailscale을 설치하고 같은 계정으로 로그인합니다.Install Tailscale on the computer serving the web viewer, your remote devices and your phone and sign in with the same account.
  2. Itda 주변 기기의 Tailscale — 어디서나에서 기기를 추가합니다.Add devices from Tailscale — anywhere in Itda's Nearby.
  3. 웹 뷰어의 QR을 Tailscale로 바꾸면 밖에서 쓸 주소가 나옵니다. Tailscale 관리 콘솔 → DNS에서 HTTPS Certificates를 켜면 HTTPS 주소 만들기도 됩니다.Switch the web viewer's QR to Tailscale for the away-from-home address. Turn on HTTPS Certificates under DNS in the Tailscale admin console to get an HTTPS address.

문제 해결Troubleshooting

“Mac이 연결을 거부했습니다”“The Mac refused the connection”

화면 공유 또는 원격 관리가 켜져 있는지 확인하세요. 연결할 계정의 접근을 허용하고, 원격 관리를 쓰면 관찰·제어 권한도 확인하세요.Check that Screen Sharing or Remote Management is enabled and your account has access. For Remote Management, also check Observe and Control permissions.

“로그인하지 못했습니다”“Couldn't sign in”

Mac은 계정의 짧은 이름과 로그인 암호(Apple ID 아님), Itda 공유 PC는 공유 암호, Linux는 VNC 암호입니다. 여러 번 틀리면 Mac이 잠시 막으니 1분 뒤 다시 하세요.Macs want the account short name and login password (not Apple ID); Itda PCs want the share password; Linux wants the VNC password. Macs block repeated failures for a minute.

휴대폰에서 웹 뷰어가 안 열려요The web viewer won't open on my phone

공유 페이지에서 웹 뷰어가 켜져 있는지 보세요(이 PC 공유의 5900 포트는 브라우저로 열리지 않습니다). 휴대폰이 같은 Wi-Fi이거나 Tailscale이 켜져 있어야 하고, 방화벽에서 ‘개인 네트워크’를 허용해야 합니다.Check the web viewer is on in Share (Share this PC's port 5900 is for VNC apps, not browsers). The phone must be on the same Wi-Fi or Tailscale, and the firewall must allow Private networks.

그래도 안 되면Still stuck?

Itda 설정 → 정보 → 로그의 마지막 줄을 붙여 GitHub 이슈로 알려 주세요.Open Settings → About → Log in Itda and paste the last lines into a GitHub issue.
